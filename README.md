# ALQOUD – القعود

منصة اجتماعية عربية أولاً لمشاركة الفيديوهات القصيرة والمحتوى الإبداعي، باستخدام Flutter.

## ما هو موجود حالياً؟
هذه النسخة هي **واجهة MVP تجريبية** وليست منصة إنتاج مكتملة:
- تنقل بين الرئيسية والاستكشاف والإنشاء والتواصل والملف الشخصي.
- موجز تجريبي ببطاقات محتوى وتفاعلات محلية (إعجاب، حفظ، متابعة، تعليقات توضيحية).
- بحث محلي في موضوعات الاستكشاف.
- واجهة إنشاء منشورات نصية كمسودات تجريبية.
- صفحة إعدادات خصوصية تجريبية.
- تصميم داكن زمردي وذهبي ودعم RTL.

## التشغيل
المتطلبات: Flutter stable وDart متوافقان.
\`\`\`bash
flutter pub get
flutter run
\`\`\`

## بناء APK
\`\`\`bash
flutter build apk --release
\`\`\`
المسار المعتاد:
\`build/app/outputs/flutter-apk/app-release.apk\`

## ما الذي لا يعمل بعد؟
- لا توجد مصادقة مستخدم حقيقية أو قاعدة بيانات متصلة.
- بطاقات الفيديو الحالية عناصر تجريبية وليست ملفات فيديو متدفقة.
- رفع الصور والفيديو، التعليقات المنشورة، الرسائل، الإشعارات، البث المباشر، البحث الشامل، التحليلات والمدفوعات غير مفعّلة.
- إعدادات الخصوصية الحالية محلية ولا تفرض حماية على الخادم.

## خارطة الطريق للإنتاج
1. Firebase project وربط FlutterFire وAuthentication.
2. Firestore schema وقواعد صلاحيات آمنة.
3. Storage للفيديو والصور مع حدود حجم ونوع الملف.
4. معالجة فيديو على الخادم (ترميز متعدد الدقات، صور مصغرة، CDN).
5. Feed ranking، متابعة، إعجاب، تعليقات، حفظ، وسوم وبحث.
6. أدوات الإبلاغ والحظر ومراجعة المحتوى وسجلات الإدارة.
7. إشعارات آمنة، إعدادات خصوصية افتراضية، وضوابط عمرية مناسبة.
8. اختبارات، مراقبة أخطاء، سياسات خصوصية وشروط استخدام، ثم إطلاق تدريجي.

## ملاحظات أمان
- لا ترفع مفاتيح أو أسرار إلى Git.
- لا تفتح صلاحيات Firestore أو Storage للعامة.
- لا تُطلق الرسائل أو البث المباشر قبل وجود الإبلاغ والحظر ومراجعة البلاغات وإعدادات خصوصية مناسبة.
- يلزم اختبار قواعد الخادم؛ إخفاء زر في الواجهة ليس وسيلة حماية.
