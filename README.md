# ALQOUD – القعود

منصة اجتماعية لمشاركة الفيديوهات القصيرة والمحتوى الإبداعي، مبنية باستخدام Flutter لتستهدف Android وiOS.

## حالة المشروع
هذه هي نقطة البداية للمشروع: واجهة Flutter أولية وهوية بصرية عربية. لم يتم بعد ربط Firebase أو بناء خدمات الفيديو والرسائل والإشعارات.

## المتطلبات
- Flutter SDK (stable)
- Dart SDK المتوافق مع Flutter
- Android Studio أو Android SDK لبناء Android
- Xcode على macOS لبناء iOS

## التشغيل
```bash
flutter pub get
flutter run
```

## بناء APK
```bash
flutter build apk --release
```
سيظهر الملف عادةً في:
`build/app/outputs/flutter-apk/app-release.apk`

## الهيكل المخطط
- `lib/main.dart`: نقطة تشغيل التطبيق والثيم والتنقل الأولي.
- `lib/features/feed/`: موجز الفيديوهات.
- `lib/features/auth/`: التسجيل وتسجيل الدخول.
- `lib/features/profile/`: الملفات الشخصية.
- `lib/features/upload/`: رفع المحتوى.
- `lib/data/`: مستودعات البيانات وخدمات Firebase.

## مراحل التطوير
1. تأسيس الواجهة والتنقل والهوية البصرية.
2. المصادقة والملفات الشخصية باستخدام Firebase.
3. رفع الفيديوهات والتخزين وتشغيلها.
4. التفاعلات والتعليقات والمتابعة والبحث.
5. الإشعارات والإبلاغ وأدوات إدارة المحتوى.
6. الاختبارات وتحسين الأداء وتجهيز الإصدارات.

> تنبيه: لا تضع مفاتيح API أو ملفات أسرار Firebase في GitHub. استخدم إعدادات آمنة وقيود صلاحيات مناسبة قبل إطلاق أي نسخة عامة.
